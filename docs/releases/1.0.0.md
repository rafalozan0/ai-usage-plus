# AI Usage Plus 1.0.0

The first release of AI Usage Plus, an independently maintained open-source
fork of [AI Usage](https://github.com/burakgon/ai-usage-menubar) by Burak Gon.

- Track the Antigravity Argon quota pool and send the current CLI user agent.
- Add a DeepSeek provider that shows your API balance as a bar from your
  starting balance down to zero, with the official DeepSeek logo.
- Fix provider cards overlapping the footer while scrolling the popover.
- Fix the Grok icon looking thin and cut off.
- Add an Edit menu so text fields accept paste.
- Ship under a new bundle identifier (`com.rafalozan0.aiusageplus`) with its own
  update feed, so it can be installed next to the original app.

Install with Homebrew: `brew install --cask rafalozan0/tap/ai-usage-plus`.
