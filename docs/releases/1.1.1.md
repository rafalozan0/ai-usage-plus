# AI Usage Plus 1.1.1

- Use AI Usage Plus in Spanish. The app follows your macOS language and stays
  in English for languages it doesn't ship yet.
- Stop repeated Warp and Droid Keychain permission dialogs during automatic
  refreshes. Permission is requested only with **Allow Keychain Access…** on
  the affected provider's card.
- Reuse authorized credentials in memory, checking item metadata for CLI login
  changes and sign-out instead of repeatedly reading the secret.
- Replace timed Keychain subprocesses for these providers with native access,
  so a pending permission request is no longer killed after 60 seconds.
- Keep Warp and Droid usage when the app or CLI rotates its own tokens during
  a refresh. Only a sign-out or a different account discards it.
- Suggest **Always Allow** in the Keychain permission message, so macOS
  doesn't ask again.
- Show Droid's Standard and Core limits as two aligned rows, and never mix
  separate pools in one row. Antigravity now lists the Claude pool before
  Argon.
- Remove the hard-edged dark band around provider cards in the scrolling
  panel.
- Open the panel more smoothly. A closed panel stays ready for 90 seconds, so
  reopening it skips rebuilding the interface during the opening animation.
  After that it is released as before.
- Show the last update time with minute precision, so a hidden panel no longer
  redraws every second.
